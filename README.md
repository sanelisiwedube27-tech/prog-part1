## About the Project
This is Part 1 of the QuickChat application. It handles the user registration and login system. The program checks inputs against strict rules to make sure they are secure and formatted correctly.

---

## Validation Rules Implemented

1. **Username:** Must have an underscore (`_`) and be 5 characters or less.
2. **Password:** Must be at least 8 characters, have a capital letter, a number, and a special character.
3. **Phone Number:** Must start with `+27` and have exactly 9 digits after that.

---

## How to Run It
1. Open the project in **NetBeans**.
2. Open `Main.java`.
3. Right-click inside the file and click **Run File**.
4. Follow the prompts in the output window to register and log in.
